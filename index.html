Waypoints NextGen

A clearer, faster and more personal waypoint experience for Vintage Story. Create useful map markers with a redesigned editor, more than 200 categorized icons, precise HEX colors and smart target suggestions.

Client-side 200+ icons New UI Custom colors Icon scale Plug and play

Make every waypoint useful at a glance

Waypoints NextGen expands the vanilla waypoint system without replacing the map itself. It focuses on the parts you use most: creating a marker, choosing its appearance and recognizing it later among many other points on the map.

  • Redesigned Add and Edit windows with the same clear workflow in both views.
  • More than 200 SVG icons organized into categories for faster browsing.
  • Advanced color picker with HEX input, curated defaults and a persistent custom palette.
  • Sharper map rendering with high-resolution caching and configurable outlines.
  • Independent scaling for waypoint icons and the player marker.
  • Vanilla and modded icons together in one categorized picker.

NEW IN 2.2.0-dev.1 EXPERIMENTAL

Smart waypoint suggestions

Look at a block or creature and press V. The mod identifies the target using its technical data, fills the localized name and position, and reuses a profile you have already saved for the same kind of target. The first time a target is encountered, you remain in control of its icon and color.

V - create a waypoint with automatic target suggestion.

Shift + V - open the editor without automatic suggestion.

Ctrl + Shift + V - open the mod configuration window.

Suggestions are designed to work with content from other mods without requiring a hard-coded list. Because the system is still experimental, unusual targets may need a manual correction before saving. It can be disabled in the mod settings.

Create a marker in seconds

A waypoint editor built for choice

The icon and color pickers are part of the waypoint window, so the result is visible while you edit it. Categories keep large icon collections manageable, while the live preview shows the selected icon, fill color and outline before you save.

  • The last icon category is remembered between sessions.
  • Your recent manual waypoint name, icon and color are restored when no target profile applies.
  • The custom color palette is saved when the window closes, avoiding unnecessary writes while editing.
  • The last opened palette tab Default or Custom is remembered.
  • HEX values are accepted without typing the # character.

Readable icons at every map scale

High-resolution icon caching keeps SVG artwork crisp, while automatically generated underlays and outlines help light, dark and open-shaped icons remain visible over the world map. Outline thickness and icon scale can be adjusted independently, and the player marker can be kept above waypoint icons.

No manual setup required

Install the mod on the client and start the game. Waypoints NextGen automatically creates the required configuration files and default target profiles. Recent update highlights

2.2.0-dev.1

  • Added persistence for the most recently created waypoint, including its category, icon, and color.
  • Improved custom color palette saving. The palette is now saved once when the window is closed instead of being written repeatedly.
  • Added saving of the last active tab related to palettes.
  • Added the experimental automatic waypoint suggestion system.
  • Added configuration options for automatic waypoint suggestions.
  • Added automatic creation of default configuration files when no configuration exists, providing a plug-and-play setup.
  • Added shared target profiles, allowing related targets to use the same icon while keeping individual names and colors. For example, different clay types can share one icon while retaining their own colors and names.
  • Added a new `Shift + V` hotkey for creating waypoints without automatic suggestions.
  • Added a new `Ctrl + Shift + V` hotkey for open UI waypoints config.
  • Renamed the `trader_buildingmaterials` icon to `trader_buildmaterials`.
  • Renamed the `trader_treasure` icon to `trader_treasurehunter`.
  • Added a new logo.

2.1.1

  • The icon `boat.svg` has been renamed to `sailboat.svg`.
  • Update modinfo.json
  • The icon `black_red_white_currant.svg` has been renamed to `currant.svg`; the configuration file for AutoMarker needs to be updated.
  • Added hover feedback for the IconPicker.
  • Added high-resolution waypoint icon caching for sharper rendering.
  • Added automatic icon underlay generation using morphological closing, hole filling, and distance transforms for cleaner outlines.
  • Improved rendering performance by caching generated icon textures and reusing them instead of regenerating them repeatedly.
